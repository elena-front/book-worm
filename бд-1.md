1. Установка зависимостей npm i sequelize sequelize-cli pg pg-hstore dotenv

2. Настройка путей Sequelize CLI const path = require('path');

module.exports = { 'config': path.resolve('db', 'database.js'), 'models-path':
path.resolve('db', 'models'), 'seeders-path': path.resolve('db', 'seeders'),
'migrations-path': path.resolve('db', 'migrations'), };

3. Создание структуры папок Sequelize npx sequelize-cli init

4. Настройка переменных окружения В корне проекта создай .env: DB_NAME= DB_USER= DB_HOST=
   DB_PASS= PORT= ACCESS_TOKEN_SECRET= REFRESH_TOKEN_SECRET=

---

Создай .env.example (та же структура, но без твоих секретов/паролей).

5. Конфиг подключения к базе данных Создай/заполни файл db/database.js:
   require('dotenv').config();

module.exports = { development: { username: process.env.DB_USER, password:
process.env.DB_PASS, database: process.env.DB_NAME, host: process.env.DB_HOST, dialect:
'postgres', logging: false, seederStorage: 'sequelize', seederStorageTableName:
'SequelizeData', }, test: { username: 'root', password: null, database: 'database_test',
host: '127.0.0.1', dialect: 'mysql', }, production: { username: 'root', password: null,
database: 'database_production', host: '127.0.0.1', dialect: 'mysql', }, };

6. Скрипты в package.json В package.json добавь (или приведи к такому виду) scripts:
   "scripts": { "test": "echo \"Error: no test specified\" && exit 1", "start": "node
   src/server.js", "dev": "nodemon src/server.js", "db": "sequelize db:drop && sequelize
   db:create && sequelize db:migrate && sequelize db:seed:all" }

7. Запусти PostgreSQL Перед работой с командами Sequelize база (PostgreSQL) должна быть
   запущена.

8. Базовые команды работы с БД npx sequelize db:drop # удалить БД npx sequelize
   db:create # создать БД

9. Создание моделей (и миграций автоматически) npx sequelize model:generate --name User
   --attributes name:string,favouriteProducts:integer

10. Связи между таблицами (Associations + Foreign Key) 10.1 В моделях (папка models)
    Добавляешь ассоциации, например:

class Band extends Model { static associate({ Album }) { this.hasMany(Album, { foreignKey:
'band_id' }); // или this.belongsTo(Album, { foreignKey: 'band_id' }) } }

10.2 В миграциях (папка migrations) В миграции добавляешь внешний ключ, например: band_id:
{ type: Sequelize.INTEGER, references: { model: "Albums", key: "id", }, onDelete:
"CASCADE", },

11. Миграции (создание таблиц) npx sequelize db:migrate # применить миграции (создаст
    таблицы) npx sequelize db:migrate:undo # откатить последнюю миграцию

12. Сиды (заполнение таблиц данными) Создать сид: npx sequelize-cli seed:generate --name
    tag

Применить все сиды: npx sequelize-cli db:seed:all

Откатить все сиды: npx sequelize-cli db:seed:undo:all

13. “Сделать всё одной командой” npm run db
